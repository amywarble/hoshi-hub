# Security Policy

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public GitHub issue.

Use [GitHub's private vulnerability-reporting form](https://github.com/amywarble/pocket-kgs-support/security/advisories/new). Include the affected Pocket KGS version, impact, reproduction steps, and any suggested mitigation. Remove unrelated personal data from screenshots and logs.

If the private reporting form is unavailable, email the Pocket KGS developer at [hoshihatchery@gmail.com](mailto:hoshihatchery@gmail.com?subject=Pocket%20KGS%20security%20report). Do not disclose the report in a public issue, and never include a KGS password.

You should receive an acknowledgment within seven days. Please allow a reasonable time to investigate and release a fix before public disclosure.

For abuse by a KGS user rather than a software vulnerability, follow the [Community Guidelines](https://amywarble.github.io/pocket-kgs-support/community-guidelines/) or contact the KGS administrators at [admin@gokgs.com](mailto:admin@gokgs.com).
