_施行日：2026年10月27日_

本ポリシーは、Android 用 Pocket KGS、Windows・macOS・Linux 用 KGS Nova、Windows・Linux 用 Mobi、および本サポートサイトを対象とします。3つのクライアントはいずれも KGS と American Go Association（AGA）の公式な支持を受けています。共通の取り扱いを説明した後、アプリ別の保存内容と設定を記載します。

## データを取り扱う主体

各クライアントは KGS Go Server に直接接続します。クライアントの開発者は KGS サーバーを運営しておらず、アカウント、モデレーション、記録、保存期間を管理しません。KGS は独立したサービスで、独自の [利用規約とプライバシー情報](https://www.gokgs.com/tos.jsp) が適用されます。

各クライアントに広告、利用状況分析、自動クラッシュレポート送信はありません。開発者は個人情報を販売せず、ターゲティング広告やアプリ間追跡に利用しません。また、KGS アカウント、チャット、棋譜、アバター、講師音声のコピーを別のサーバーに保管しません。

## 取り扱う情報と目的

クライアントと利用機能に応じ、次の情報を取り扱います。

- **アカウントとプロフィール：** KGS の認証情報、メールアドレス、プロフィール文、アバター、ランク、アカウント状態、設定。
- **通信とユーザー関係：** 部屋・対局のチャット、個人・オフラインメッセージ、友人・ファン・拒否リストとメモ、その他の KGS コンテンツ。
- **対局と活動：** 着手、棋譜、注釈、結果、対局申込、参加部屋、マッチング設定。Mobi は、着手生成と対局処理のために、設定した囲碁エンジンと対局情報を交換します。
- **接続情報：** 永続的な KGS クライアント識別子、アプリ・プロトコルのバージョン、言語、OS とアーキテクチャ、実行環境情報、接続状態。接続時に KGS は IP アドレスを受け取ります。
- **端末内設定と診断：** 設定、キャッシュ、下記のアプリ別診断情報。

これらはログイン、KGS セッション、コンテンツ表示、利用者の操作または設定されたボット操作の KGS への送信、設定の記憶、および利用者が詳細を共有した場合の問題調査に使われます。

Pocket KGS と Nova は、権限を持つ講師が明示的にライブ配信を開始した場合のマイク音声も取り扱い、受信した講師音声を再生します。停止操作または該当セッションの終了で配信を停止します。いずれも開発者向けの別の録音を作成しません。Mobi は講師音声の操作機能を提供しません。

## 情報の送信先

- **KGS：** アカウント・接続情報、通信、対局活動、要求された変更を受け取ります。他の利用者に見える内容は、利用する KGS 機能によります。
- **認証情報プロバイダーとエンジン：** OS の認証情報プロバイダーと選択した Mobi エンジンは、下記のとおり、それぞれの規約に基づいて情報を取り扱います。
- **GitHub：** 本サイトと公開課題管理は GitHub がホストし、[GitHub プライバシーステートメント](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) が適用されます。公開課題と添付資料は誰でも閲覧できます。Nova の不具合報告は、アプリのバージョン、OS、アーキテクチャ、実行環境を含む編集可能な下書きをブラウザーで開きます。課題の送信やログ添付は自動では行いません。
- **法令と安全：** 開発者に提供された情報は、法令遵守、不正調査、利用者保護、権利や安全の保護に合理的に必要な場合、保存または開示することがあります。

## 通信と安全性

各クライアントの旧式 KGS 接続には TLS やエンドツーエンド暗号化がありません。ログインプロトコルは送信前にパスワードを変換しますが、その他の通信は経路にアクセスできる者が読み取ったり改変したりできる場合があります。信頼できるネットワークを使ってください。

KGS はすべての会話を記録し、報告調査の際に管理者が確認できると説明しています。秘密にすべき情報を KGS で共有しないでください。サーバー側の保存は KGS が管理し、棋譜はアーカイブに残ることがあります。

### Pocket KGS

Pocket は設定、通知の選択、KGS クライアント識別子を Android のアプリ専用領域に保存し、アバターをキャッシュに保存します。Android はキャッシュを削除することがあります。Pocket は専用データをバックアップしないよう Android に要求します。ストレージ消去またはアンインストールで、これらの端末内データを削除します。

認証情報の保存を選ぶ場合、Android Credential Manager と選択したプロバイダーが独自の規約で管理します。Pocket は認証情報のロック解除に使う生体情報を受け取りません。プロバイダー側の保存情報は別途削除が必要な場合があります。

製品版のエラー診断は Android のシステムログに出力します。任意の診断ログを有効にすると、そのセッションの詳細が増えます。リリースログはバージョン、イベントテンプレート、例外の型、スタックトレースを残し、実行時引数の値、例外メッセージ、ソースファイルのパスを省く設計です。Android、端末管理者、ログを渡した相手が閲覧できる場合があります。

ゲスト利用、認証情報保存の選択、Pocket または Android での通知停止、マイク権限の拒否、配信しない選択、拒否リストによる対応する交流の遮断とコンテンツ非表示が可能です。

### KGS Nova

- **データベース：** OS の KGS Nova 用ローカルアプリデータフォルダー（Windows は `%LOCALAPPDATA%\KGS Nova`）の `data.db` に、保存アカウントのメタデータ、クライアント識別子、設定、アプリ状態を保存します。データベース全体は暗号化されません。
- **パスワード：** Windows は現在の Windows ユーザー向け DPAPI でデータベース内の保存パスワードを保護します。macOS は Keychain、Linux は Secret Service を使います。OS が解除や許可を求める場合があります。データベースの他の部分は暗号化されません。
- **診断：** リリース版のエラーは同じフォルダーの `client.log` とローテーションされる `client.archive*.log` に保存します。任意のセッション診断では詳細が増えます。リリースログは Pocket と同じ省略方針です。開発版では、より詳しい `logs.txt` やコンソール・デバッグ出力が作られる場合があります。
- **その他のファイル：** 同じフォルダーに `sgf` 作業領域、復旧ファイルとバックアップ、`analysis` のエンジン・モデルがあります。書き出した棋譜などは、選択した保存先に残ります。

ファイルや OS アカウントにアクセスできる人やソフトウェアが読み取れる場合があります。Nova のアンインストールや置き換えでは、データベース、ログ、書き出し、キーリング項目が削除されるとは限りません。ゲスト利用、認証情報保存の選択、対応する個人メッセージの制御、拒否リスト、マイク配信をしない選択、ローカルデータの削除が可能です。

### Mobi

Mobi は登録済み KGS アカウントを必要とします。`KGS_PASSWORD` からパスワードを読み取り、Mobi 自身は永続保存しません。起動スクリプト、環境設定、サービス管理ツールに記載した認証情報はそこに残る場合があります。それらと OS アカウントを保護してください。起動されたエンジンは環境変数を引き継ぐことがあります。

TOML 設定にはアカウント名、サーバー、エンジンのパス、対局設定が含まれる場合があります。Mobi は KGS クライアント識別子をローカルファイルに保存します。マッチング時の既定は .NET のローカルアプリデータ領域（Windows は `%LOCALAPPDATA%`）内の `Kgs.Gtp/identities/<server-and-account-hash>`、マッチングなしの場合は `Kgs.Gtp/client-id` です。`account.clientIdFile` または `--client-id-file` で変更できます。

状態、エラー、エンジン診断は stderr に出力します。出力のリダイレクトやサービス管理ツールの保存によってログが残ります。Pocket/Nova のリリースログ省略規則は適用されず、ユーザー名、対局詳細、パス、エンジン出力を含む場合があります。共有前に確認してください。エンジンは独自のログ、棋譜、その他のファイルを作成したり、独自のネットワーク通信を行ったりする場合があります。その説明書とプライバシー慣行を別途確認してください。Mobi は診断を開発者に自動送信しません。

エンジン、設定、保存出力、ローカルファイルは利用者が管理します。操作と診断は [Mobi ユーザーガイド]({% include page-url.html key='mobi/user-guide' %}) を参照してください。

## 保存期間、削除、その他の選択肢

開発者はローカルファイルや診断を自動受信しません。任意に送信したコピーは、問い合わせ対応や法令・安全上の必要により保存する場合があります。公開 GitHub 課題と履歴は、GitHub の機能と方針に基づき編集・削除されるまで残ります。

共有するプロフィール情報を選び、対応する設定で KGS のメールアドレスを非公開にできます。ファイル削除やアンインストールでは、KGS 保管データは削除されません。アカウントとサーバーデータの削除は KGS 管理者が担当します。共通の申請方法と各クライアントの端末内削除は [アカウントとデータの削除]({% include page-url.html key='global/account-and-data-deletion' %}) を参照してください。

Pocket KGS は13歳未満の子どもを対象としていません。KGS は公開の通信サービスです。未成年者が利用する前に、保護者が規約と適切性を確認してください。公開課題に子どもの個人情報を掲載しないでください。

## 変更と連絡先

OS とクライアントを更新し、KGS 専用のパスワードを使い、共有前にログを確認してください。完全に安全なシステムはありません。脆弱性は [セキュリティポリシー]({% include page-url.html key='global/security-policy' %}) に従って報告してください。

クライアントの変更に伴い本ポリシーを改訂する場合があります。施行日は公開版を示します。機密性のない問い合わせは [公開課題管理](https://github.com/amywarble/hoshi-hub/issues/new/choose) を利用してください。非公開のアプリ・プライバシー相談は [hoshihatchery@gmail.com](mailto:hoshihatchery@gmail.com)、KGS アカウント、サーバーデータ、モデレーションは [admin@gokgs.com](mailto:admin@gokgs.com) に連絡してください。
