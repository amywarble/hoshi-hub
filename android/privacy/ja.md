_施行日：2026年10月27日_

Pocket KGS は KGS Go Server（「KGS」）用の Android クライアントで、KGS の公式な承認を受けています。本ポリシーは、扱う情報、その目的、送信先、利用者の選択肢を説明します。対象は Pocket KGS と本サポートサイトです。KGS は独立したサービスで、独自の [利用規約とプライバシー条件](https://www.gokgs.com/tos.jsp) があります。

## データを扱う主体

アプリは KGS に直接接続します。開発者はクライアントを提供しますが、KGS サーバーを運営せず、その記録、管理、保存期間を決定しません。広告、利用状況分析、自動クラッシュ報告はありません。開発者は個人情報を販売しません。

## アプリが扱う情報

利用する機能に応じて、次の情報を扱います。

- **アカウントとプロフィール：** KGS 利用者名、パスワード、メールアドレス、自己紹介、アバター、棋力、アカウント状態、プロフィール設定。
- **通信と利用者コンテンツ：** 公開の部屋／対局チャット、私信、オフラインメッセージ、棋譜、注釈、対局申し込み、その他 KGS と送受信する内容。
- **音声：** 資格のある講師が明示的に講義音声の配信を開始した場合のマイク音声。KGS を通じて対局参加者へライブ送信します。利用者が停止するか対象セッションが終了すると配信を停止し、開発者向けの別録音は作成しません。
- **交流情報：** 友人、ファン、無視リスト、およびそれらに付けたメモ。
- **対局と活動：** 対局／観戦、着手、結果、設定、部屋への参加、対局申し込み、KGS 機能の操作。
- **端末と接続：** 永続的な KGS クライアント識別子、アプリ／プロトコルのバージョン、言語・地域、OS とバージョン、CPU アーキテクチャ、ランタイムの提供元・バージョン、ネットワーク状態、接続に必要な情報。接続時に KGS は必ず IP アドレスを受け取ります。
- **通知：** Android 通知を表示できる KGS イベントについてのローカル設定。
- **キャッシュ：** 効率的な動作に使うアバターとアプリ設定。
- **診断ログ：** 製品版は Android システムログにエラー診断を記録します。任意の診断ログを有効にすると、そのセッションではより詳しいイベントを記録します。製品版ログはバージョン、イベントのテンプレート、例外の型とスタックを保持し、実行時の引数値、例外メッセージ、ソースファイルのパスを除く設計です。共有前に確認してください。Pocket KGS は自動送信しません。Android、端末管理者、利用者がログを渡した相手は閲覧できる場合があります。

## 利用目的

ログインとセッション維持、依頼された既存プロフィールの更新、部屋・利用者・対局・プロフィール・メッセージ等の表示、着手・メッセージ・プロフィール変更・アバター・音声・その他指定操作の送信、端末内の設定・識別子・通知設定の記憶、有効にした通知の表示、自発的に共有された情報による障害診断に使います。ターゲティング広告やアプリ横断追跡には使いません。

## 送信先

次の目的に必要な範囲のみで情報を開示します。

- **KGS：** サービス提供のため、アカウント、通信、対局活動、プロフィール、講義音声、端末／ランタイム、クライアント識別子、接続情報を送信します。KGS 機能が公開または共有する内容は他の利用者に見えます。
- **Android 認証情報プロバイダー：** パスワード保存を選択した場合、Android Credential Manager と選択したプロバイダーが独自のプライバシー条件に従って利用者名とパスワードを扱います。Pocket KGS は認証解除に使う生体情報を受け取りません。
- **GitHub：** 本サイトと公開 Issue は GitHub がホストします。投稿は [GitHub のプライバシーステートメント](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) に従い、公開 Issue は誰でも閲覧できます。
- **法令と安全：** 法令遵守、利用者保護、不正調査、アプリや他者の権利・安全の保護に合理的に必要な場合、開発者が受領した情報を保存・開示することがあります。

## 通信と伝送に関する注意

KGS はすべての会話を記録し、通報調査時に管理者が確認できるとしています。秘密にする必要のある情報をチャットに書かないでください。

従来の KGS プロトコルは、現代的な TLS 保護接続を提供しません。パスワードはログインプロトコルで変換して送信しますが、その他の通信は TLS でもエンドツーエンドでも暗号化されません。通信経路を監視・妨害できる人が内容を読んだり改変したりする可能性があります。信用できないネットワークでの使用を避けてください。

## 保存と保持

識別子と設定はアプリ専用領域、アバターは Android キャッシュに保存します。空き容量不足で Android がキャッシュを削除する場合があります。アプリデータの消去やアンインストールで専用領域のデータは消えますが、Android Credential Manager の認証情報は別途パスワード管理アプリから削除する必要がある場合があります。

開発者は KGS アカウント、チャット、対局、アバター、講義音声のサーバーコピーを別途保持しません。KGS 自身が保存期間を決め、会話を記録し、棋譜をアーカイブで公開し続ける場合があります。

アカウントと関連サーバーデータの削除は [admin@gokgs.com](mailto:admin@gokgs.com?subject=KGS%20account%20deletion%20request) に、利用者名と登録メールアドレスを添えて依頼してください。パスワードは送らないでください。管理者が本人確認を行い、依頼を処理します。ローカル削除を含む詳細は [アカウントとデータの削除]({% include page-url.html key='android/account-and-data-deletion' %}) をご覧ください。公開 Issue と履歴は GitHub の機能・方針に従って編集または削除されるまで残ります。

## 利用者の選択

KGS サイトでアカウントを作らずゲスト利用、パスワード保存の選択、可能な場合の登録メール非公開、アバターやプロフィール変更の選択、マイク拒否と講義配信の不使用、アプリ／Android での通知停止、無視機能による対応した交流の拒否と内容非表示、ローカルデータ消去またはアンインストール、[削除手順]({% include page-url.html key='android/account-and-data-deletion' %}) の実行が可能です。

## 子ども

Pocket KGS は13歳未満を対象としていません。KGS は利用者同士が交流する公開サービスです。未成年者に許可する前に保護者が規約と適切性を確認してください。公開 Issue に子どもの個人情報を投稿しないでください。

## セキュリティ

完全に安全なシステムはありません。端末とアプリを更新し、KGS 専用のパスワードを使い、公開 Issue に認証情報や私的な内容を投稿しないでください。脆弱性の連絡は [セキュリティポリシー]({% include page-url.html key='global/security-policy' %}) に従ってください。

## 変更

アプリの変更に伴い本ポリシーを変更することがあります。重要な改訂時は施行日を更新します。変更後も利用を続ける場合、その後の利用には改訂版が適用されます。
