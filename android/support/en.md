## Pocket KGS app help

For a reproducible app bug or a feature request, [choose a public issue form](https://github.com/amywarble/hoshi-hub/issues/new/choose). Search existing issues first when practical.

Include the Pocket KGS version, Android version, what you expected, what happened, and minimal steps to reproduce the problem. Screenshots are useful only after you remove usernames, messages, email addresses, and other personal information.

Never post any of the following in a public issue:

- passwords, recovery information, access tokens, or credentials;
- email addresses, legal names, IP addresses, or other private identifiers;
- private messages or non-public game/room content;
- diagnostic logs you have not reviewed and redacted; or
- abusive, sexual, illegal, or child-safety material.

## KGS account, server, or moderation help

Pocket KGS is an independent client. For password recovery, account status, server-side data, or KGS moderation, contact a KGS administrator in the service or email [admin@gokgs.com](mailto:admin@gokgs.com).

To request deletion of a KGS account and its associated server-side data, follow the [Account and Data Deletion instructions]({% include page-url.html key='android/account-and-data-deletion' %}). Do not put account details in a public GitHub issue.

See the [Community Guidelines]({% include page-url.html key='android/community-guidelines' %}) for blocking and reporting instructions.

## Privacy, safety, and security

Do not use a public GitHub issue for a privacy request, deletion request, sensitive safety report, or security vulnerability.

- Read the [Privacy Policy]({% include page-url.html key='android/privacy' %}).
- Request [Account and Data Deletion]({% include page-url.html key='android/account-and-data-deletion' %}).
- Report a vulnerability using the repository's [private security-reporting form](https://github.com/amywarble/hoshi-hub/security/advisories/new).
- Email the Pocket KGS developer at [hoshihatchery@gmail.com](mailto:hoshihatchery@gmail.com) for a private app, privacy, or sensitive safety concern.

Concerns about KGS accounts, server-side data, moderation, or the KGS service should instead go to [admin@gokgs.com](mailto:admin@gokgs.com).
