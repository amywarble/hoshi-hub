## Pocket KGS のヘルプ

[Pocket KGS の問題を報告](https://github.com/amywarble/hoshi-hub/issues/new?template=bug_report.yml)するか、[機能を提案](https://github.com/amywarble/hoshi-hub/issues/new?template=feature_request.yml)してください。可能であれば、先に[既存の報告](https://github.com/amywarble/hoshi-hub/issues)をご確認ください。

問題の報告に技術的な知識は必要ありません。一度しか起きていなくても、何が起きたかをご自身の言葉でお知らせください。分かる範囲で記入していただければ、必要に応じて追加でお尋ねします。バージョン、操作手順、スクリーンショットは任意です。画像を共有する前に、個人情報や非公開の内容を隠してください。

GitHub を使っていない場合は、[hoshihatchery@gmail.com](mailto:hoshihatchery@gmail.com) へのメールでもアプリの問題を報告できます。

公開 Issue に、パスワード・復旧情報・トークン・認証情報、メールアドレス・本名・IP アドレス・非公開の識別子、私信や非公開の対局／部屋の内容、未確認または機密情報を除去していないログ、虐待的・性的・違法な資料や子どもの安全に関わる資料を投稿しないでください。

## KGS のアカウント・サーバー・管理に関する相談

Pocket KGS は独立したクライアントです。パスワードの復旧、アカウント状態、サーバーデータ、モデレーションは KGS 管理者または [admin@gokgs.com](mailto:admin@gokgs.com) にお問い合わせください。

アカウントと関連サーバーデータの削除は [削除手順]({% include page-url.html key='global/account-and-data-deletion' %}) に従ってください。公開 Issue にアカウント情報を載せないでください。ブロックや通報は [コミュニティガイドライン]({% include page-url.html key='android/community-guidelines' %}) をご覧ください。

## プライバシーと安全

プライバシー・削除の依頼、機微な安全上の報告、脆弱性の連絡に公開 Issue を使わないでください。

- [プライバシーポリシー]({% include page-url.html key='global/privacy' %})
- [アカウントとデータの削除]({% include page-url.html key='global/account-and-data-deletion' %})
- [脆弱性の非公開報告](https://github.com/amywarble/hoshi-hub/security/advisories/new)
- アプリ、プライバシー、機微な安全問題の個別相談：[hoshihatchery@gmail.com](mailto:hoshihatchery@gmail.com)。

KGS アカウント、サーバーデータ、モデレーション、KGS 自体については [admin@gokgs.com](mailto:admin@gokgs.com) へご連絡ください。
