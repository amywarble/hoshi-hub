# KGS Nova desktop support

KGS Nova is an independent desktop client for the [KGS Go Server](https://www.gokgs.com/), available for Windows, macOS, and Linux. It is not affiliated with or endorsed by KGS.

These pages cover the desktop app:

- [Support]({{ '/desktop/support/' | relative_url }})
- [Privacy Policy]({{ '/desktop/privacy/' | relative_url }})
- [Terms of Use]({{ '/desktop/terms/' | relative_url }})
- [Community Guidelines]({{ '/desktop/community-guidelines/' | relative_url }})
- [Account and Data Deletion]({{ '/desktop/account-and-data-deletion/' | relative_url }})

The separate [Pocket KGS pages]({{ '/' | relative_url }}) cover the Android app.

For desktop bugs and feature requests, [open a public GitHub issue](https://github.com/amywarble/pocket-kgs-support/issues/new/choose) and identify the app as **KGS Nova desktop**. Do not include credentials, private messages, or other sensitive information.
