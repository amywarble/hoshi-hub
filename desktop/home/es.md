KGS Nova es un cliente independiente del [KGS Go Server](https://www.gokgs.com/) para Windows, macOS y Linux, sin afiliación ni respaldo de KGS.

Estas páginas cubren la aplicación de escritorio:

- [Privacidad]({% include page-url.html key='desktop/privacy' %})
- [Condiciones de uso]({% include page-url.html key='desktop/terms' %})

- [Eliminación de cuentas y datos]({% include page-url.html key='desktop/account-and-data-deletion' %})

Para Android, consulte [Pocket KGS]({% include page-url.html key='android/home' %}).
