本ポリシーは Windows、macOS、Linux 用 KGS Nova に適用されます。独立したクライアントで、KGS との提携関係や公認はありません。KGS は別サービスとして独自の [規約とプライバシー情報](https://www.gokgs.com/tos.jsp) を定めています。

## 扱う情報

KGS に直接接続します。機能に応じ、認証情報とプロフィール、部屋、チャットと私信／オフラインメッセージ、交流リストとメモ、棋譜と着手、対局申し込み、アバター、設定を扱います。指定された操作を KGS に送り、その応答を表示します。他者への公開範囲は KGS 機能によります。

永続的クライアント識別子、プロトコル版、言語・地域、OS、アーキテクチャ、ランタイム情報を KGS に送ります。KGS は接続元のネットワークアドレスも受け取ります。

資格のある講師が配信を始めるとマイク音声を KGS 経由で対局参加者に送り、受信時は KGS の音声を再生します。停止操作またはセッション終了で配信が終わります。開発者用の別録音はありません。

広告、利用分析、自動クラッシュ送信はありません。開発者はアカウント、メッセージ、対局、音声の別サーバーコピーを保持しません。

## ローカル保存と診断

- **データベース：** 作業ディレクトリの `data.db` に保存アカウントのメタデータ、識別子、設定、アプリ状態を保持します。データベース全体は暗号化されません。
- **パスワード：** Windows は現在の OS 利用者向け DPAPI でデータベース内を暗号化、macOS はキーチェーン、Linux は Secret Service を使用します。OS の許可や解除が必要な場合があります。この保護はデータベースの他の部分を暗号化しません。
- **ログ：** アプリディレクトリの `logs.txt` とコンソール／デバッグ出力を使います。ファイルは起動時に置き換えます。バージョン、システム、利用者名、部屋／対局 ID、操作、例外、接続やメッセージ失敗時のプロトコルデータを含む場合があります。個人情報がないとは限りません。自動送信しません。
- **保存ファイル：** 明示的に書き出した棋譜等は指定した場所に残ります。

ファイルや OS アカウントにアクセスできる人・ソフトウェアが読める場合があります。アンインストールや置換ではデータベース、ログ、書き出し、認証ストアの項目が消えない場合があります。[削除手順]({% include page-url.html key='desktop/account-and-data-deletion' %}) をご覧ください。

## 通信と第三者サービス

従来の接続には TLS やエンドツーエンド暗号化がありません。パスワードを変換しても全通信の監視・干渉は防げません。信頼できるネットワークを使ってください。

KGS は会話を記録し、管理者が確認できるとしています。秘密にする必要のある情報を共有しないでください。サーバーの管理と保存は KGS が決定します。

サポートと Issue は [GitHub のプライバシーステートメント](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) に従います。リンクはブラウザーを開きます。不具合報告ではバージョン、OS、アーキテクチャ、ランタイムの編集可能な下書きを開き、送信やログ添付を自動実行しません。送信された公開 Issue と添付は公開されます。

## 選択肢と問い合わせ

ゲスト利用、認証情報保存の選択、対応する私信制限、無視、マイク配信の不使用、ローカルファイル削除が可能です。KGS アカウントの削除は管理者が行います：[手順]({% include page-url.html key='desktop/account-and-data-deletion' %})。

子どもの個人情報を Issue に投稿しないでください。未成年者の利用前に保護者が規約と通信機能を確認してください。
