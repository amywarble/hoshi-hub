Introducing KGS Nova

KGS Nova is a modern desktop client for Windows, macOS, and Linux.

With support from the American Go Foundation (AGF), Nova will become KGS's new official client. The goal is to do everything the legacy client can do, and more, while preparing KGS for future features such as Fischer time.

Download KGS Nova Getting started →

Updates, built in

Nova checks for updates automatically. When a new version is available, download it in the app and restart when you're ready.

Highly customizable

Seven interface themes, six goban materials, and controls for the details: stones, grid contrast, coordinates, and move markers. Theme and goban choices are independent.

Current status

Nova is fairly mature but still changing quickly, with published updates about every one to two days. That pace will slow as the client stabilizes.

Simul and rengo games have not yet been tested. Both are on the testing list.
