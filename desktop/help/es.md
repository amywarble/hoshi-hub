## Instalar y actualizar

Descargue un paquete **KGS Nova** de [GitHub Releases](https://github.com/amywarble/hoshi-hub/releases). Elija su sistema operativo y procesador y siga las instrucciones de instalación de esa versión. Cada versión enumera los paquetes disponibles.

## Iniciar sesión

Inicie sesión con su usuario y contraseña KGS o continúe como invitado. Para crear una cuenta, use el enlace de registro de la pantalla de acceso; abre el sitio web KGS.

## Jugar y explorar

Elija Jugar para buscar rival o crear una partida. Use Salas para conversar y observar partidas, y Personas para buscar jugadores. Ver/editar abre archivos SGF para estudio local. Las preferencias controlan apariencia y ajustes.

En Acerca de, las instalaciones compatibles permiten buscar y descargar actualizaciones y reiniciar para aplicarlas. Termine las partidas activas y guarde o cierre los documentos SGF antes de reiniciar. Si no está disponible, use las descargas e instrucciones de la versión.
